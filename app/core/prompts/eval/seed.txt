You are generating training data for a payment intention detection model.
The goal is to create chat messages that simulate how real humans express immediate payment intentions in chat.

## Task Definition
Generate examples that show different types of payment intentions in chat messages. The model needs to distinguish between:

- **PAYMENT_REQUEST_INTENT**: The user is requesting to receive money.
- **PAYMENT_SEND_INTENT**: The user is declaring they will send money right now or in near future.
- **SMART_PAYMENT_SYSTEM_COMMAND**: The user gives an imperative instruction to a system to execute a payment (e.g., “Pay Alice $20 now”).

**Important Rules**
1. Do not generate messages where the money is already sent. Only intended, requested, or commanded payments are valid.
❌ Wrong: "Just sent you 3$" 
✅ Correct: "I'l send you 3$"

2.Do not generate long-term or delayed intent. Only immediate or short-term intent is valid.
❌ Wrong: “I’ll pay you enough on next year.”
✅ Correct: “I'll pay you tomorrow”

3. Include these kind of messages
- simple (should take up 50% of the dataset) message that frequently (or likely) appear in everyday chat, can be from any type of person.
- Medium - message that also everyday message but with more persona related
- Hard - message that only appear in some specific condition, personsa (such as tech related, academic, ...)
- Extremely - message that only appear by some personas, undersome special condition that it not occur everyday.

- "Send me cash please" (simple)
